# 🎮 CYBER XO // Cyberpunk Tic-Tac-Toe 3.0

> Визуально ошеломляющая, кинематографичная веб-игра «Крестики-Нолики» в стилистике Cyber-Neon & Glassmorphism с процедурным звуком на Web Audio API, интерактивными частицами и непобедимым искусственным интеллектом (Minimax).

## ⚡ Особенности проекта

### 🎨 1. Киберпанк-дизайн & Glassmorphism
### 🕹 1. Главное меню и 4 боевых режима
- **Футуристическое Главное меню**: Интерактивные кибер-карточки выбора симуляции, панель настройки противника и сложности.
- **Классика 3x3**: Эталонные правила игры на поле 3 на 3.
- **Infinity XO (Исчезающие метки)**: У каждого игрока на поле может находиться максимум 3 метки! 4-й ход растворяет 1-й. Самая старая фишка заранее пульсирует сигнальным маяком опасности. Ничьих больше нет!
- **Кибер-Блиц**: 5 секунд на каждый ход с тающей неоновой шкалой времени и нарастающим пульсом отсчета. Не успел — ход теряется!
- **Сетка 4x4**: Масштабное тактическое поле 16 клеток. Победит тот, кто первым соберет 4 лазера в ряд!

### 🎨 2. Неоновые темы & CRT-стилизация
- **4 темы оформления на лету**:
  - ⚡ **Cyber Neon** (Cyan / Magenta) — эталонный киберпанк.
  - 🟢 **Matrix Protocol** (Green Phosphor / Emerald) — эстетика цифрового кода.
  - 🌅 **Outrun Sunset** (Hot Orange / Violet) — ретровейв 80-х.
  - 🩸 **Blood Chrome** (Crimson / Platinum) — агрессивный кибер-металл.
- **CRT-сканлайны & Glitch**:
  - Полноэкранный ретро-эффект развертки ЭЛТ-монитора (`CRT FX`).
  - Хроматическая аберрация (размытие RGB-каналов) и цифровой глитч при победе, сгорании времени или смене тем.
- **Интерактивный 3D Tilt**: Доска плавно реагирует на перемещение курсора мыши и гироскоп сенсорных экранов, наклоняясь в перспективе.
- **Интерактивный космос**: Полноэкранный `<canvas id="bg-canvas">` с созвездиями и частицами, динамически реагирующими на мышь.

### ⚡ 3. Кинематографичные анимации
- **Лазерный разрез X**: Векторный SVG с поочередной прорисовкой линий и вспышкой в точке пересечения.
- **Плазменное кольцо O**: Круговая закрутка SVG-контура на 360° со следом свечения.
- **Лазер победы**: Динамический лазерный луч рассекает выигрышную цепочку клеток.
- **Эффект триумфа**: Плавная кинематографичная тряска экрана (`screen-shake`), пульсация выигрышных клеток и взрыв неонового салюта на `<canvas id="fx-canvas">`.

### 🧠 4. Продвинутый искусственный интеллект (AI)
- **Новичок (Easy)**: Играет легко и непринужденно, допуская ошибки.
- **Тактик (Medium)**: Проверяет возможность мгновенной победы, блокирует опасные ходы игрока, захватывает центр и углы.
- **Мастер (Unbeatable)**: Безупречный алгоритм **Minimax** с альфа-бета отсечением, эвристикой для поля 4х4 и симуляцией скользящего окна в режиме Infinity XO.
- **Эффект «ИИ думает...»**: Натуральная задержка хода (360–450 мс) с неоновым пульсирующим индикатором «АНАЛИЗ...».

### 🔊 5. Процедурный звук & Synthwave BGM (Web Audio API)
Никаких внешних MP3/WAV файлов — абсолютно всё генерируется математически в реальном времени:
- **Фоновая музыка (Ambient Synthwave)**: бесконечный процедурный саундтрек — глубокий sub-бас drone (A1 + E2) и пентатонический minor-арпеджиатор.
- **Ход X**: Футуристический высокочастотный лазерный свист (sawtooth sweep + фильтрация).
- **Ход O**: Глубокий плазменный резонирующий тон (суб-бас dual-oscillator).
- **Дематериализация**: Спектральный свист растворения метки в режиме Infinity XO.
- **Блиц-таймер**: Ритмичный пульсирующий тик обратного отсчета и аварийный зуммер.
- **Победа**: Восходящий мажорный кибер-арпеджио из 4 нот.
- **Ничья**: Нисходящий футуристический вздох.
- Кнопка выключения звуковых эффектов и кнопка BGM музыки с сохранением настроек в `localStorage`.

### 🌐 6. Онлайн Мультиплеер P2P (WebRTC)
- **Бессерверная дуэль (Serverless PeerJS)**: Прямое соединение браузер-в-браузер без необходимости в выделенном бэкенд-сервере.
- **Двустороннее подтверждение реванша (Mutual Rematch)**: Ожидание нажатия обоих игроков, бейджи готовности `(1/2)` и плавающий баннер в игре.
- **Чередование сторон (Auto-swap Sides)**: Автоматическая смена ролей `X` ⇄ `O` при каждом новом раунде реванша для спортивной справедливости.
- **Кибер-реакции и пинги**: Панель быстрых сигналов (`⚡`, `🔥`, `💀`, `🤖`, `GG WP`, `ХОРОШ!`, `ОЙ...`) с парящими неоновыми голограммами над полем.
- **Генератор комнат & Ссылки-приглашения**: Вход по 6-значному коду или прямой ссылке `?room=CODE`.
- **Локальный фоллбэк (BroadcastChannel)**: Мгновенное кросс-вкладочное соединение.

### 📳 7. Тактильный виброотклик (Mobile Haptic Feedback)
- Плотная физическая отдача на смартфонах через `navigator.vibrate`:
  - Лёгкий щелчок (12 мс) при установке крестика или нолика.
  - Двойной тревожный пульс при критическом тиканье блиц-таймера.
  - Торжественный каскад вибраций при победе и завершении матча.
  - Резкий глитч-импульс при переключении неоновых тем и CRT-эффекта.

### 🏆 8. Кибер-статистика и Достижения
- **Табло боевой статистики**: Общее число матчей, побед, процент побед (`Win Rate %`), текущая серия побед (`Streak 🔥`) и максимальный рекорд в `localStorage`.
- **7 кибер-достижений** с динамическими всплывающими HUD-карточками и звуковым фанфаром:
  - ⚡ *«Первая кровь»* — первая победа в игре.
  - 🧠 *«Нейромант»* — победа над ИИ на сложности «Мастер».
  - ⏱️ *«Кибер-молния»* — победа в режиме Блиц 5с.
  - ♾️ *«Квантовый парадокс»* — 8 ходов в одном раунде Infinity XO.
  - 🌐 *«Сетевой призрак»* — триумф в онлайн P2P дуэли.
  - 🔥 *«Серийный взломщик»* — серия из 3 побед подряд.
  - 📐 *«Архитектор 4×4»* — победная линия из 4 клеток.

### 📱 9. Progressive Web App (PWA) & Offline-режим
- **Установка как нативное приложение**: Поддержка установки на Android, iOS, Windows и macOS благодаря манифесту `manifest.json` и адаптивным векторным иконкам (`icon-192.svg`, `icon-512.svg`).
- **Автономная работа (Service Worker `sw.js`)**: Стратегия кэширования `Cache-First` позволяет запускать игру и наслаждаться всеми режимами даже в самолете без интернета.

## 📁 Архитектура проекта

```text
XO/
├── index.html               # Семантическая разметка, PWA мета-теги и экраны
├── manifest.json            # Манифест PWA (автономный запуск, темы, иконки)
├── sw.js                    # Service Worker (кэширование и offline fallback)
├── icon-192.svg             # Векторная неоновая иконка приложения 192x192
├── icon-512.svg             # Векторная неоновая иконка приложения 512x512
├── start.bat                # Скрипт быстрого запуска сервера в Windows
├── css/
│   ├── variables.css        # Дизайн-токены, 4 неоновые темы, свечения
│   ├── style.css            # Сброс стилей, базовый лейаут, канвасы, экраны
│   ├── components.css       # Доска, карточки режимов, меню, P2P панель, HUD
│   └── animations.css       # Keyframes: лазер, плазма, CRT flicker, глитч
└── js/
    ├── app.js               # Точка входа: роутинг, PWA и P2P оркестрация
    ├── state.js             # Модель состояния (режимы, история, localStorage)
    ├── ai.js                # ИИ: Easy, Medium, Minimax с альфа-бета отсечением
    ├── audio.js             # Синтезатор звуков и Synthwave BGM на Web Audio API
    ├── p2p.js               # WebRTC P2P сетевой движок (PeerJS + BroadcastChannel)
    ├── particles.js         # Canvas: космический фон и салют победы
    └── ui.js                # Управление DOM, 3D-наклон доски, SVG-анимации
```

## 🚀 Локальный запуск проекта

Поскольку используются нативные модули JavaScript (`type="module"`), проект запускается через любой локальный HTTP-сервер:

### Способ 1: Windows (1 клик)
Просто дважды кликните по файлу `start.bat` — откроется локальный сервер и браузер.

### Способ 2: VS Code
Правый клик по `index.html` → **Open with Live Server**.

### Способ 3: Node / NPX
```bash
npx serve .
# или
npx http-server .
```
